## Publicação
1. Envie o conteúdo deste ZIP para um repositório GitHub independente.
2. No Cloudflare Pages, crie um projeto conectado ao repositório.
3. Como é um site estático puro, deixe o comando de build vazio e o diretório de saída como `/` (raiz do projeto).
